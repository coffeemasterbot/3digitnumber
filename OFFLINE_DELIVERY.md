# Offline downloadable edition

The original existing Site now offers downloads/lost-found-money-offline.html from the #offline section. This is one self-contained 7.3 MiB HTML file: save it, open in a desktop browser, and disconnect the internet. No installation, localhost server, browser extension, ChatGPT sign-in, or first online launch is required after downloading.

The offline edition removes runner/Jetpack online leaderboard scripts and controls, updates online-score wording, embeds scripts/styles/images and open-source notices, and blocks network connections with a connect-src none content policy. Garden's existing local Top 10 and other on-device best scores remain. Nothing is submitted to the shared leaderboard. The existing online Site remains available with its online features.

The exporter in build-offline.cjs consumes the existing built pages; it does not replace game engines or story content. It packages the story, seven-day plan, five games and accessible untimed range. An embedded document router preserves replay/menu buttons, optional nested FPS, range navigation, and forest query options without HTTP or file-relative dependencies. A local-file origin mismatch discovered in QA was repaired in the exported menu's source-window-checked message handler. Jetpack's page reload is routed back to its embedded page. Local preferences/progress are separate from the public website. Keep the same filename/location and browser; clearing data or moving the file can affect saved progress.

Files: build-offline.cjs (exporter); build.cjs (build integration); source/presentation-section.html, landing-build.cjs, landing.css (real download/UI and one authoritative presentation template); OFFLINE_README.txt; tests/offline-export.test.cjs, qa-offline.cjs, qa-offline-download.cjs and QA results; generated dist/downloads and dist/client/downloads plus landing assets.

Validation: production build; 41 Node logic/API/export tests; 15 inline script syntax blocks; actual browser download byte comparison; direct file:// launch in a fresh Edge browser context with offline:true before navigation. Story clue, persisted progress and language, nested optional FPS open/exit, all five game starts, FPS settings, separate untimed range open/exit, garden planting/mowers, Jetpack sound/reload, menu/reload navigation and embedded images were checked. Network listener recorded zero HTTP requests or API calls. No page exceptions. Screenshots inspected. Browser-file checks use desktop Edge with software WebGL. Physical iOS/Android file viewers and Safari/Firefox were not tested; the download page recommends desktop browsers and explains the phone limitation. This run checks offline integration, not every ending or an uninterrupted full 20-wave playthrough; original story and game rules are unchanged.
