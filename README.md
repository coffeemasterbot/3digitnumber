# 戶口三位數 website v1

《人生失物認領處》為主線的校園理財網站。

## 網站內容

- 首頁、主線介紹、四款獨立小遊戲、七日行動、講座資訊及私隱說明。
- 主線保留四幕故事、證人、帳單疑點、海濱對話、現金流安排及行動卡。
- 預算守護花園：三種植物、五路防守、三波帳單與資源分配。
- 散紙追蹤：三線跑酷，左右換線與跳躍。
- 優惠氣流：按住上升，放開下降，辨認需要及湊單。
- 冰火同行：三關平台機關、元素池、雙角色收集、開閘合作；可單人切換或同機雙人。
- 獨立遊戲與主線進度分開保存，不會以試玩跳過主線。

遊戲程式、角色插畫及街機配樂為本項目原創；計劃機構標誌保留官方識別。
遊戲機制參考植物防守、三線跑酷、升降飛行與雙角色平台合作等類型。

## 進度及私隱

主線進度沿用本機儲存，獨立小遊戲另有本機紀錄。網站毋須登入，未加入問卷或遙測資料收集。
七日行動會在主線現金流安排完成後開啟。每日解鎖及行動卡下載沿用故事內功能。
換裝置或清除瀏覽器資料，進度不會跟隨轉移。

## 編輯與預覽

dist/ 為可部署網站：index.html、style.css、app.js、story/index.html 及 assets/talk-poster.png。
source/ 保留故事及原有小遊戲基底；garden-duo.js 提供植物防守與雙角色合作，garden-duo-art.js 及 garden-duo.css 提供畫面與響應式版面。
以 Node 執行 build.cjs 重新整合故事頁。執行 preview.cjs 後開啟其 Local 網址。
目前講座資料為11月9日1104、11月12日6580，第一場18:00–19:00、第二場18:00–19:00；報名連結仍待提供。

## 驗證

執行 qa.cjs 可依次驗證三波防守、三關合作、同機雙人、手機雙指、原有兩款小遊戲、音效開關、主線問答銜接、進度分離及直橫屏版面。需要 Playwright 與 Microsoft Edge。
網站先以私人版本發佈，未變更為公開參與者網站。


散紙追蹤與優惠氣流保留 60 秒獨立試玩／主線短挑戰。植物防守及合作遊戲按關卡倒數；三種難度分別調整時間、資源、敵人及機關。講座日期及時間沿用已確認資料。

遊戲體驗更新 2026年11月4日：固定120Hz物理、跳躍輸入緩衝及離地寬限、觸控多指操作、逐關提示、失焦自動暫停、每關重試、主線與獨立紀錄分開。新玩法使用原創植物、帳單與元素角色。


## 整體優化（2026年11月4日）

首頁採用米白、深綠及暖橙編排，加入四張原創遊戲插圖及計劃機構資訊。噴射飛行員、跑手、冰火角色及拾取物以 Canvas 向量繪製，支援高解像螢幕。

四款遊戲均有輕鬆／標準／挑戰模式。跑酷及飛行需在60秒內達到收集目標並避免耗盡機會；植物防守及冰火合作每關倒數，失敗可以重試該關。標準與挑戰冰火關卡加入間歇電閘。暫停會停止倒數及配樂。

arcade-score.js 為四款遊戲安排原創鼓、低音及旋律，最後15秒加快節奏；使用原有共用音量及靜音設定，不含商業遊戲原聲。game-sprites.js 提供角色繪圖；landing-build.cjs 與 landing.css 編輯首頁。

機構分工依照官方2026–2027計劃：合辦機構為聖雅各福群會及投資者及理財教育委員會；資助機構為香港交易所慈善基金。官方來源：https://www.sjscareersparkle.org/個人理財大使計劃2627 。標誌取自使用者指定參考頁的計劃頁尾原檔，無修改標誌本體。
