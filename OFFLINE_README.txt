戶口三位數 / Lost & Found Money Journey — Offline Edition

1. Download lost-found-money-offline.html and save it to your computer.
2. Double-click the file, or open it in Chrome, Edge or Firefox. No installation or sign-in is needed.
3. You can disconnect the internet and play the story and all five games. All game graphics, scripts and sounds are included.
4. Online leaderboards are disabled. Local scores, preferences and story progress use browser storage. Nothing is uploaded. Keep the same filename/location and browser; moving the file or clearing browser data can affect saves. Online-site saves are separate and are not copied into this file.
5. To share offline, send this HTML file to a friend or copy it by USB. External Instagram/help links still need internet.
6. Desktop browsers are recommended. Mobile file viewers may show a preview instead of running games; mobile offline file opening has not been verified on physical iOS/Android devices. Use the public website if your phone cannot open local HTML.
7. 3D games need a browser/device that supports WebGL. Sound starts after interaction.
